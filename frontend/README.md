# WorkflowWeaver Frontend

React 18 + Vite + Tailwind CSS. This is the UI half of WorkflowWeaver — see the
[repo root README](../README.md) for the full project overview, setup instructions, environment
variables, and architecture.

```bash
npm install
npm run dev      # http://localhost:5173, proxies /api/* to the backend on :8000
npm run build    # production build to dist/
npm run preview  # preview the production build
npm run lint      # ESLint
```
